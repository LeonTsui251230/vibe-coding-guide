## 这是什么

本仓库是一份面向中文用户的 Vibe Coding 实战指南。我们不讲大道理，只给能直接用的工作流、提示词和避坑清单。

## 目录

- [📖 方法论与文档](documents/)
- [💡 提示词库](prompts/)
- [🛠 技能库](skills/)
- [📦 通用库](../libs/)

## 快速开始

1. 通读根目录 `README.md` 的「入门七步」。
2. 根据你的场景，从 `prompts/coding_prompts/` 挑选一个提示词开始。
3. 做出第一个可运行版本后，再回来看 `documents/` 里的复盘方法。
