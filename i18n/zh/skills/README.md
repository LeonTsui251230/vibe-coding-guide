# 🛠 技能库

当某个领域的提示词反复使用时，就可以把它升级为 **Skill**：系统提示词 + 参考资料 + 工作流检查清单的组合。

## 目录结构

```
i18n/zh/skills/
├── README.md
└── <skill-name>/
    ├── SKILL.md        # 技能入口与触发方式
    └── references/     # 参考资料、规则、模板
```

## 示例技能

- `mini-program/`：微信小程序 Vibe Coding 技能
- `cover-design/`：AI 封面设计技能
- `talking-head-cut/`：口播视频初剪技能
