# 📖 文档库

`i18n/zh/documents/` 收录 Vibe Coding 的方法论、实战经验和可复用模板。

## 目录结构

```
i18n/zh/documents/
├── README.md
├── Methodology and Principles/   # 心法与原则
├── Tutorials and Guides/         # 工具与教程
└── Templates and Resources/      # 模板与资源
```

## 分类说明

### Methodology and Principles
关于 Vibe Coding 的核心理念、工作哲学和避坑原则。

### Tutorials and Guides
具体工具的配置、使用指南和操作教程。

### Templates and Resources
可复用的项目模板、代码结构规范和资源列表。

## 贡献新文档

1. 将文档放在最贴合的分类下。
2. 必要时创建新分类目录。
3. 更新本 README 以反映变更。
