# MVP 项目结构

一个人用 AI 做产品时，推荐保持目录极简：

```
my-product/
├── README.md          # 项目一句话说明 + 启动方式
├── docs/              # 需求、设计稿、复盘
├── src/               # 源码
├── tests/             # 关键流程测试
├── scripts/           # 一键部署/备份脚本
└── .env.example       # 环境变量示例（不要放真密钥）
```

## 原则

- 不到 1000 行代码不分层
- 所有脚本都要有 `--help`
- 文档和代码同步更新
